# Adaptive Chameleon Pattern

## Описание

`adaptive_chameleon_pattern.bin` — это специальный бинарный паттерн, генерируемый программно.  
Он представляет собой многослойную структуру данных, построенную на математических принципах согласования частот, фаз, импедансов и временных интервалов.

Паттерн создаётся одним исполняемым файлом и записывается на диск в виде `.bin`-файла с атрибутом Read-Only.
https://montagnikrea-star.github.io/noninput/pattern.html
---

## Основные свойства

| Свойство | Описание |
|---------|----------|
| Широкий частотный диапазон | От сверхнизких до сверхвысоких частот |
| RLC-модель | Несколько резонансных контуров на разных частотах |
| Фазовое согласование | Жёсткая привязка фаз частотных составляющих |
| Согласование 50/75 Ом | Минимизация отражений по аналогии с волновым сопротивлением |
| Анти-Rowhammer слой | Разрушение периодических структур, благоприятных для Rowhammer |
| Скрученный провод | Компенсация по принципу сложенного и скрученного проводника |
| Устойчивость к фрагментации | Самодостаточные блоки разных масштабов (4K / 16K / 64K) |
| Тикрейт-оптимизация | Структуры под 64-tick, 128-tick и sub-tick |
| Контроль целостности | Цифровая подпись, 64-bit checksum, CRC32 |
| Оптимизация доступа | Выравнивание под cache-line и страницы SSD |

## Как это работает

### 1. Генерация
Программа создаёт несколько внутренних слоёв разного размера (по умолчанию 4 + 8 + 16 + 32 МБ).  
Каждый байт вычисляется как смесь:

- Ортогональных частотных компонент
- RLC-ответов на разных частотах
- Согласованных фаз
- Компенсирующих (противофазных) сигналов
- Анти-периодических составляющих
- Временных структур тикрейтов

### 2. Многомасштабность
Паттерн содержит самодостаточные блоки разных размеров.  
Даже при сильной фрагментации файла контроллером диска отдельные части сохраняют ключевые свойства.

### 3. Частотное и фазовое согласование
Все основные частоты привязаны к одной опорной фазе.  
Это уменьшает хаотические рассогласования и делает структуру более предсказуемой с точки зрения спектра.

### 4. Тикрейт-слой
В паттерн встроены временны́е ритмы, соответствующие:

- 64 tick/s
- 128 tick/s
- sub-tick (более мелкое разбиение)

### 5. Защита целостности
При создании файла вычисляются:

- 64-битная контрольная сумма
- Цифровая подпись
- CRC32

Файл помечается как Read-Only.

## Как использовать

1. Скомпилировать генератор (Visual Studio 2022, x64).
2. Запустить исполняемый файл.
3. Получить `adaptive_chameleon_pattern.bin`.
4. Разместить файл в нужных местах (корень диска, важные папки и т.д.).
5. При желании — использовать резидентный загрузчик, чтобы удерживать паттерн в оперативной памяти.

## Важные ограничения

Паттерн является **структурой данных**. Он:

- Не заменяет аппаратную защиту памяти (ECC, TRR)
- Не устраняет акустический шум компьютера
- Не влияет напрямую на сетевой код игр
- Не является антивирусом или средством защиты от атак

Его действие ограничено математическими и структурными свойствами самого файла и его размещения в памяти/на диске.
