Паттерн + разрешения браузера

Отметьте нужные разрешения и нажмите Подтвердить. Браузер сам покажет системные окна «Разрешить / Блокировать» там, где это поддерживается.
Список разрешений
Persistent Storage
Просит браузер не удалять данные сайта автоматически. Диалог бывает не всегда — зависит от политики браузера.
не запрошено
Screen Wake Lock
Не даёт экрану гаснуть, пока паттерн работает. Отдельный системный диалог обычно не показывается, но доступ может быть запрещён.
не запрошено
Notifications
Стандартный запрос браузера с кнопками «Разрешить» / «Блокировать». Для паттерна не обязателен, но даёт явный user-gesture диалог.
не запрошено
Clipboard Write
Опционально. Может вызвать системный запрос при попытке записи в буфер (в некоторых браузерах).
не запрошено
Важно: браузер показывает нативные окна только для части API. Persistent Storage и Wake Lock часто работают без классического Allow/Deny окна.
